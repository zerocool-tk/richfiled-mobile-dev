# References

Sources consulted while designing and building the Smart Pantry Manager, in Harvard style. The
Android developer documentation is the primary reference for every API used in the app; the prescribed
module textbook supplied the overall architecture (a helper class plus a data source for a local
database, and the Activity/Fragment/list pattern).

## Prescribed and recommended module sources

Press. (Prescribed textbook for Mobile App Development 700.)

Johannesburg: Richfield Graduate Institute of Technology.

## Notes on referencing

- All Android API references point at the official documentation for the version in use (API 34).
- The referencing style follows the Harvard convention used by the institution: author, year, title in
  italics, source, and an access date for online sources.
